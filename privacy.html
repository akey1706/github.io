Политика конфиденциальности

Для виджетов «Сумма по списку» и «Идентификаторы аккаунта» для amoCRM

Дата публикации: 7 октября 2026 года

1. Общие положения

Настоящая Политика конфиденциальности определяет порядок обработки информации при использовании виджетов «Сумма по списку» и «Идентификаторы аккаунта» для amoCRM, разработанных Антоном Кучуком (далее — «Разработчик»).

Используя виджеты, пользователь подтверждает, что ознакомился с настоящей Политикой.

2. Какие данные используются

Виджеты получают из amoCRM только те данные, которые необходимы для выполнения заявленных функций.

Виджет «Сумма по списку»

  • данные сделок и значения выбранных пользователем числовых полей — для расчёта сумм;
  • информация о текущем списке и применённых фильтрах — для корректного отображения результата;
  • настройки выбранных для суммирования полей — для работы виджета.

Виджет «Идентификаторы аккаунта»

  • идентификатор аккаунта;
  • идентификаторы и основные сведения о пользователях аккаунта;
  • идентификаторы воронок и этапов;
  • идентификаторы и названия доступных пользовательских полей;
  • другие идентификаторы, необходимые для отображения справочной информации.

3. Цели обработки

Получаемая информация используется исключительно для работы функциональности соответствующего виджета: отображения информации, расчётов, поиска, формирования справочника идентификаторов и сохранения пользовательских настроек.

4. Передача данных третьим лицам

Виджеты не предназначены для продажи, передачи или распространения данных пользователей amoCRM третьим лицам.

Обмен данными с amoCRM осуществляется средствами и API самой платформы в рамках предоставленных пользователем разрешений.

Разработчик не использует полученные через виджеты данные для рекламы, рассылок или формирования профилей пользователей.

5. Хранение данных

Виджеты используют данные только в объёме, необходимом для выполнения своих функций. Пользовательские настройки могут сохраняться в соответствии с реализацией конкретного виджета.

Если данные не требуются для работы виджета после выполнения операции, они не предназначены для отдельного долговременного хранения разработчиком.

6. Доступ к данным в amoCRM

Виджет работает в рамках прав доступа, предоставленных ему пользователем при установке. Разработчик не получает больше данных, чем необходимо для заявленной функциональности.

Пользователь самостоятельно управляет установкой и удалением виджетов в своём аккаунте amoCRM.

7. Безопасность

Разработчик принимает разумные технические меры для защиты используемой информации от несанкционированного доступа, изменения или раскрытия.

При этом передача информации через интернет и сторонние сервисы не может гарантировать абсолютную безопасность.

8. Права пользователя

Пользователь вправе прекратить использование виджета и удалить его из аккаунта amoCRM. При необходимости пользователь также может обратиться к разработчику по вопросам, связанным с обработкой информации.

9. Изменение Политики

Разработчик вправе обновлять настоящую Политику при изменении функциональности виджетов или порядка обработки информации. Актуальная версия Политики публикуется на этой странице.
